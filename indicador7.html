Indicador de Calidad 7 (IQ7): Uso adecuado de nutrición parenteral total (NPT)

Para evaluar el uso adecuado de nutrición parenteral total en la unidad, el indicador se ha operativizado bajo los siguientes criterios técnicos:

  • Población diana (\(N\)): Para la operacionalización del IQ7, se consideraron como población diana los pacientes de la cohorte ENPIC que recibieron nutrición parenteral durante su estancia en UCI, identificados mediante la presencia de una fecha válida en la variable Inicio_NPT.

  • Casos favorables (\(n\)): El numerador se definió como el número de pacientes con NPT en los que constaba una justificación documental de la indicación. Se consideró evidencia de indicación registrada la presencia de información válida en al menos una de las siguientes variables: INDICA_NTP, Causa_ReposoIntestinal o INDICA_NTP_PocoAporte.

La proporción de cumplimiento se calculó como el cociente entre los pacientes con NPT e indicación documentada y el total de pacientes que recibieron NPT.

\[IQ7 = \left( \frac{\text{Nº de enfermos con NPT e indicación documentada}}{\text{Nº total de enfermos que recibieron NPT}} \right) \times 100\]

Para cuantificar la precisión de la estimación se calculó el intervalo de confianza binomial al 95%.

# 1. Denominador: Pacientes que recibieron NPT (tienen fecha de Inicio_NPT)
pacientes_NPT <- subset(enpic, !is.na(Inicio_NPT))
Denominador_IQ7 <- nrow(pacientes_NPT)

# 2. Numerador: Pacientes con indicación correcta justificada
# Usamos el operador '|' (OR) para comprobar si AL MENOS UNA de las columnas tiene datos
Numerador_IQ7 <- sum((!is.na(pacientes_NPT$INDICA_NTP)) | (!is.na(pacientes_NPT$Causa_ReposoIntestinal)) | (!is.na(pacientes_NPT$INDICA_NTP_PocoAporte)), na.rm = TRUE)

# 3. Cálculo del indicador (porcentaje)
IQ7 <- (Numerador_IQ7 / Denominador_IQ7) * 100

# 4. Estadísticas: Intervalos de confianza al 95%
test_IQ7 <- prop.test(Numerador_IQ7, Denominador_IQ7, conf.level = 0.95)
IC_Inf_IQ7 <- round(test_IQ7$conf.int[1] * 100, 2)
IC_Sup_IQ7 <- round(test_IQ7$conf.int[2] * 100, 2)

El IQ7 alcanzó una tasa de cumplimiento del 75.9%, correspondiente a 148 pacientes con NPT e indicación documentada sobre un total de 195 pacientes que recibieron nutrición parenteral. El intervalo de confianza binomial al 95% fue de [69.16% - 81.59%].

Dado que el estándar definido para este indicador es ≥90%, el resultado se sitúa por debajo del nivel de calidad esperado. En concreto, 47 pacientes que recibieron NPT no presentaban una justificación documental registrada en las variables analizadas, lo que representa el 24.1% de los pacientes tratados con NPT.

La interpretación principal es que existe un margen de mejora en la documentación de la indicación de la NPT. Este incumplimiento puede reflejar una indicación clínica no suficientemente justificada en el registro asistencial o, alternativamente, una cumplimentación incompleta de los motivos clínicos que llevaron a su prescripción. Por tanto, el resultado debe interpretarse principalmente como un déficit de trazabilidad documental de la indicación, sin asumir de forma automática que todos los casos no documentados correspondan a una prescripción clínicamente inadecuada.

Análisis univariante

Se comparan las características clínicas, nutricionales, terapéuticas y evolutivas entre dos grupos:

  • NPT justificada: 148/195 (75,9%).

  • NPT no justificada: 47/195 (24,1%).

Para llevar a cabo esta comparativa, se emplean los siguientes métodos:

  • Variables continuas: Se emplean pruebas no paramétricas de Mann-Whitney para datos que siguen una distribución asimétrica, presentando los datos mediante mediana y rango intercuartílico, y la prueba t de Student para datos que siguen una distribución normal, presentando los datos como media ± desviación estándar.

  • Variables categóricas: Se utiliza la prueba de chi-cuadrado, o el test exacto de Fisher cuando existen frecuencias esperadas bajas.

Finalmente, se formatean los valores de p, destacando visualmente los resultados estadísticamente significativos y las asociaciones con tendencia, y se genera una tabla comparativa final entre ambos grupos.

formatear_p <- function(p) ifelse(is.na(p), "-", ifelse(p < 0.001, "<0.001", as.character(round(p, 3))))

# 3. Funciones para tabla univariante
# 3.1. Variables asimétricas: Mediana [Q1-Q3] + Mann-Whitney
crear_fila_mw_iq7 <- function(data, var, nom) {
  d <- data %>% filter(!is.na(.data[[var]]), !is.na(Grupo_IQ7_NPT))
  if (n_distinct(d$Grupo_IQ7_NPT) < 2) return(data.frame(Variable = nom, p = "-"))
  t <- d %>% group_by(Grupo_IQ7_NPT) %>% summarise(v = sprintf("%.1f [%.1f - %.1f]", median(.data[[var]], na.rm = TRUE), quantile(.data[[var]], 0.25, na.rm = TRUE), quantile(.data[[var]], 0.75, na.rm = TRUE)), .groups = "drop") %>% pivot_wider(names_from = Grupo_IQ7_NPT, values_from = v)
  p <- tryCatch(wilcox.test(as.formula(paste(var, "~ Grupo_IQ7_NPT")), data = d)$p.value, error = function(e) NA_real_)
  t %>% mutate(Variable = nom, p = formatear_p(p)) %>% select(Variable, everything())}

# 3.2. Variables normales: Media ± DE + t-test
crear_fila_ttest_iq7 <- function(data, var, nom) {
  d <- data %>% filter(!is.na(.data[[var]]), !is.na(Grupo_IQ7_NPT))
  if (n_distinct(d$Grupo_IQ7_NPT) < 2) return(data.frame(Variable = nom, p = "-"))
  t <- d %>% group_by(Grupo_IQ7_NPT) %>% summarise(v = sprintf("%.1f ± %.1f", mean(.data[[var]], na.rm = TRUE), sd(.data[[var]], na.rm = TRUE)), .groups = "drop") %>% pivot_wider(names_from = Grupo_IQ7_NPT, values_from = v)
  p <- tryCatch(t.test(as.formula(paste(var, "~ Grupo_IQ7_NPT")), data = d)$p.value, error = function(e) NA_real_)
  t %>% mutate(Variable = nom, p = formatear_p(p)) %>% select(Variable, everything())}

# 3.3. Variables categóricas con varias categorías
crear_fila_chi_iq7 <- function(data, var, nom, niveles, etiquetas) {
  d <- data %>% filter(!is.na(.data[[var]]), !is.na(Grupo_IQ7_NPT)) %>% mutate(vc = factor(.data[[var]], levels = niveles, labels = etiquetas)) %>% filter(!is.na(vc))
  if (nrow(d) == 0 || n_distinct(d$Grupo_IQ7_NPT) < 2 || n_distinct(d$vc) < 2) return(data.frame(Variable = paste0(nom, ": sin datos suficientes"), p = "-"))
  tabla_test <- table(d$vc, d$Grupo_IQ7_NPT); p <- tryCatch(if (any(tabla_test < 5)) fisher.test(tabla_test)$p.value else chisq.test(tabla_test)$p.value, error = function(e) NA_real_)
  t <- d %>% count(Grupo_IQ7_NPT, vc) %>% group_by(Grupo_IQ7_NPT) %>% mutate(v = sprintf("%d (%.1f%%)", n, n / sum(n) * 100)) %>% select(-n) %>% pivot_wider(names_from = Grupo_IQ7_NPT, values_from = v)
  t %>% mutate(Variable = paste0(nom, ": ", vc), p = ifelse(row_number() == 1, formatear_p(p), "")) %>% select(-vc) %>% select(Variable, everything())}

# 3.4. Variables categóricas Sí/No mostrando solo "Sí"
crear_fila_chi_si_iq7 <- function(data, var, nom, niveles, etiquetas, categoria_mostrar = "Sí") {

Las diferencias clave se concentraron en variables relacionadas con el perfil nutricional y la duración temporal del soporte. Los pacientes con NPT justificada presentaron: mayor BMI: 27,7 [24,0–30,8] frente a 24,7 [22,9–29,0] kg/m² (p = 0,006); mayor duración total del soporte nutricional: 12,0 [7,0–24,2] frente a 8,0 [5,0–12,0] días (p = 0,003); mayor duración de la NPT: 7,0 [4,0–13,0] frente a 5,0 [3,0–7,5] días (p = 0,002); y mayor estancia hospitalaria: 34,0 [20,0–60,2] frente a 26,5 [15,0–39,0] días (p = 0,025).

Análisis multivariante

Regresión logística binaria multivariable

Se realizó una regresión logística binaria multivariable tomando como variable dependiente la ausencia de justificación documental de la NPT, codificada como evento frente a la NPT justificada. Como variables candidatas se incluyeron aquellas que habían mostrado asociación significativa o tendencia en el análisis univariante —p < 0,10—: BMI, riesgo nutricional por VGS, horas hasta inicio del soporte nutricional, duración total del soporte nutricional, días de NPT, infección relacionada con catéter y días de hospitalización. Se exploraron de forma sistemática combinaciones de 2 a 6 variables, comparando los modelos según AIC, AUC, número de predictores significativos y parsimonia. Conclusión Indicador de Calidad 7 (IQ7)

En conjunto, el análisis del IQ7 evidencia un cumplimiento insuficiente del estándar de calidad definido para el uso adecuado de nutrición parenteral total (NPT), entendido en este análisis como la existencia de una justificación documental registrada de su indicación.

La distribución de los 195 pacientes que recibieron NPT se divide en:

  • NPT justificada documentalmente (75,9%): Grupo mayoritario (148 pacientes), con constancia registrada de indicación clínica.

  • NPT no justificada documentalmente (24,1%): Subgrupo (47 pacientes) que concentra el principal margen de mejora del indicador.

El resultado se sitúa por debajo del estándar establecido (≥90%), por lo que existe un margen claro de mejora. No obstante, la interpretación debe ser prudente: el indicador no demuestra necesariamente que todos los casos sin registro correspondan a una indicación clínicamente inadecuada, sino que identifica una deficiencia relevante en la trazabilidad documental de la prescripción.

Caracterización de los grupos según justificación documental

Los pacientes con NPT justificada y no justificada presentaron un perfil clínico basal globalmente comparable. No se observaron diferencias significativas en edad, gravedad al ingreso ni comorbilidad, con escalas de gravedad prácticamente superponibles:

  • APACHE II: 20,4 ± 7,8 frente a 20,0 ± 8,2 (p = 0,813).

  • SAPS II: 49,0 ± 18,0 frente a 49,8 ± 16,4 (p = 0,795).

  • SOFA al ingreso: 7,0 [4,0–10,0] frente a 7,0 [4,5–9,0] (p = 0,919).

  • NUTRIC Score: 4,0 [3,0–6,0] frente a 5,0 [3,8–6,0] (p = 0,288).

Las diferencias principales se concentraron en variables nutricionales y temporales del soporte. Los pacientes con NPT justificada presentaron:

  • Mayor BMI: 27,7 [24,0–30,8] frente a 24,7 [22,9–29,0] kg/m² (p = 0,006).

  • Mayor duración total del soporte: 12,0 [7,0–24,2] frente a 8,0 [5,0–12,0] días (p = 0,003).

  • Mayor duración específica de la NPT: 7,0 [4,0–13,0] frente a 5,0 [3,0–7,5] días (p = 0,002).

  • Mayor estancia hospitalaria: 34,0 [20,0–60,2] frente a 26,5 [15,0–39,0] días (p = 0,025).

Señales exploratorias (Tendencias):

  • Riesgo nutricional (VGS): Más frecuente en el grupo justificado (59,2% vs. 42,6%; p = 0,068), sugiriendo que pacientes con peor perfil reconocido se documentan mejor.

  • Infección relacionada con catéter: Más frecuente en el grupo sin justificación (12,8% vs. 4,1%; p = 0,069).

  • Inicio del soporte: Tendió a ser más precoz en pacientes sin justificación (24,4 vs. 30,0 horas; p = 0,089).

No se observaron diferencias significativas en: Tipo global de soporte, vía de administración de NPT, complicaciones digestivas, ventilación mecánica, noradrenalina, TRR, infecciones respiratorias ni mortalidad a 28 días.

Respaldos del modelo multivariable (Regresión Logística)

El modelo multivariable reforzó la interpretación de que la ausencia de justificación no se explica por una mayor gravedad basal, sino por un patrón de menor reconocimiento nutricional y menor duración del episodio.

El modelo final (n = 185; AIC = 190,699; AUC = 0,761) mostró una capacidad discriminativa moderada. En el modelo ajustado, se asociaron de forma independiente a una menor probabilidad de NPT no justificada (mejor documentación):

  • Mayor BMI: OR 0,89; IC95% 0,81–0,97 (p = 0,007).

  • Riesgo nutricional por VGS: OR 0,28; IC95% 0,12–0,62 (p = 0,002).

  • Mayor duración de la NPT: OR 0,94; IC95% 0,89–1,00 (p = 0,046).

La infección relacionada con catéter mostró una asociación positiva con la ausencia de justificación (OR 3,36; p = 0,080), aunque únicamente como tendencia. Las horas hasta el inicio (p = 0,167) y los días de hospitalización (p = 0,554) perdieron significación independiente.

En conjunto: La documentación mejora en pacientes con mayor reconocimiento clínico-nutricional y en tratamientos prolongados. Los episodios más breves o menos caracterizados nutricionalmente concentran el mayor riesgo de falta de registro.

Análisis complementario de Cox

Como análisis exploratorio, se ajustó un modelo de Cox (n = 185; 46 eventos; AUC = 0,719). Los resultados fueron globalmente concordantes (asociaciones significativas para BMI, VGS, horas hasta inicio y días en terapia).

Sin embargo, este análisis debe interpretarse con cautela. Existió una violación global significativa de la proporcionalidad de riesgos (p = 6,5e-11). Además, el evento “NPT no justificada” es una clasificación documental, no un desenlace longitudinal real. Por ello, la regresión logística binaria constituye el análisis principal más adecuado.

Auditoría clínica y oportunidades de mejora

El problema principal radica en la falta de registro explícito en una cuarta parte de los pacientes. Las áreas de mejora prioritarias son:

  1. Reforzar la obligatoriedad de documentar el motivo antes o en el momento de iniciar la NPT.

  2. Estandarizar los motivos en la historia clínica (contraindicación NE, intolerancia grave, reposo intestinal, cirugía digestiva, etc.).

  3. Revisar los episodios de corta duración (urgentes o transitorios), donde la indicación suele quedar “asumida” pero no verificable.

  4. Incorporar campos estructurados obligatorios en la prescripción electrónica.

  5. Auditar periódicamente para distinguir entre prescripciones clínicamente inadecuadas y simples defectos de cumplimentación.

Impacto en mortalidad y relevancia del indicador

Aunque la mortalidad a 28 días fue numéricamente superior en el grupo sin justificación (29,8% frente a 25,7%), esta diferencia no alcanzó significación estadística (análisis Kaplan-Meier log-rank p = 0,514). En esta cohorte, la falta de documentación no se asoció a una peor supervivencia a corto plazo.

Sin embargo, esta ausencia de impacto en mortalidad no resta relevancia al indicador. El IQ7 evalúa la adecuación, seguridad y trazabilidad del proceso. Dado que la NPT es compleja y costosa, el objetivo no es demostrar un impacto directo en supervivencia, sino asegurar una prescripción trazable, auditable y clínicamente segura, alineada con los criterios establecidos.
